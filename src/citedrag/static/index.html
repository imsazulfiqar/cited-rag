How accurate is the search?

Every answer depends on first finding the right passages. This page measures how well that search step works.

What's being tested

  1. We wrote 10 test questions about the three sample reports. For each one, we already know which report contains the answer.
  2. Each question is run through the same search the Ask page uses.
  3. We check where the correct report appears in the results.

It tests finding the right source, not the wording of the answer. It uses no AI model, so it's free and runs in under a second. Developers use it to check that a change to the search made results better, not worse.
